## Shape Shift

https://a4-teagan-tran.onrender.com

This project is a 3D puzzle game built with Three.js called Shape Shift. Players select a shape and rotate it with the keyboard to match a randomly generated target orientation before time runs out. The project combines interactive controls, custom geometry creation, animation, scoring, and level progression. A primary challenge was coordinating the 3D rotation, timing, and game-state systems into a responsive experience while supporting both built-in and user-created shapes.
